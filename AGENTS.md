# Deledger Agent Guide

## Agent skills

### Issue tracker

Issues, specs, and decision maps are tracked as local Markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five canonical Matt Pocock skill labels without aliases. See `docs/agents/triage-labels.md`.

### Domain docs

Deledger uses a single-context domain layout rooted at `CONTEXT.md`, with durable decisions under `docs/adr/`. See `docs/agents/domain.md`.
